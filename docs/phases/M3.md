# M3 requirements: unsigned provenance generation

Status: **Not started**. Prepared 2026-11-14 from merged M2 commit
`e133687faa9c48b466ccdaf0b83ef8a31cc5893f`.
The [plan](../PLAN.md) defines scope; this is its M3 acceptance contract.
Preserve [ADR 0004](../adr/0004-m2-canonical-hashing-and-verification.md).

## Scope and boundaries

Implement unsigned `record`, in-toto Statement v1/SLSA provenance predicate v1, and offline `inspect`.
Record existing artifacts and metadata; this CLI does not run arbitrary build commands. DSSE, signing,
signer/identity policy and attestation verification remain M4. GitHub Actions integration is M5;
dependency discovery, SBOM and reproducibility checks remain M6.
Preserve M2 manifest format, canonical directory/symlink hashing, path/output protection and the
`verify --manifest` result scope. Provenance generation does not authenticate how an artifact was built.

## Format and input contract

Use `_type: https://in-toto.io/Statement/v1` and
`predicateType: https://slsa.dev/provenance/v1`. The SLSA specification version is 1.2;
the predicate URI remains `/v1`, not `/v1.2`.
Pin upstream schema sources by commit/version and checksum, document their license, and validate
fixtures offline. Format validation does not prove build honesty or any SLSA level.

Choose a versioned build-type URI in a namespace controlled by this project, and document its parameter
semantics. `https://buildtrace.dev/build/v1` was an unverified example, not an owned namespace.
The type must explain that BuildTrace is a recorder of existing artifact observations/caller claims;
it must not imply BuildTrace executed or witnessed the original build.

| Field | Required evidence or omission |
|---|---|
| subject name/digest | Unique documented names and digests computed from the selected artifacts using M2 hashing. Document directory/symlink canonical bytes. Reject ambiguous name collisions. |
| source URI/commit | Full captured commit and sanitized remote, or an explicit caller input. Observing a checkout does not prove selected artifacts were built from it, especially when dirty. |
| buildType/externalParameters | Documented recorder contract and caller-selected artifact/source parameters. Record assertions as assertions; exclude tokens, unrestricted environment and private absolute paths. |
| internalParameters/tool versions | Only allowlisted observed metadata with defined meaning. Current tool versions do not prove those tools performed the original build. |
| resolvedDependencies | Only evidence-backed entries with precise meaning. No inferred transitive dependencies or guessed GitHub workflow/build configuration; broad discovery remains M6. |
| builder.id | Explicit label under the recorder contract. It is not an authenticated identity or workflow certificate. Never invent a workflow URI for local recording. |
| invocationId | An explicit or documented deterministic recorder identifier. A random default prevents byte equality and must not be described as deterministic. |
| startedOn/finishedOn | Original build times only when explicitly supplied as caller claims; otherwise omit. Observation time is not the original build start/end. |
| byproducts | Only actually produced/captured outputs with computed digests; omit placeholders. |

Do not emit empty SHA values, abbreviated commit IDs or made-up dependencies to fill an example.
Every claim must be traceable to a defined input; identify which claims can only be checked for
consistency and which can be independently recomputed from bytes or a checkout.

## CLI, determinism and errors

- `record --sign none` produces unsigned output; unsupported signing requests fail explicitly in M3.
  Decide the unsigned default and metadata flags before implementation. `inspect` is an offline parser
  and formatter, not signature verification. Unknown predicates must never be presented as verified.
- Define the existing `.intoto.jsonl` convention precisely: one compact statement plus newline per
  recording, with bounded parsing and explicit handling of empty/multiple/malformed records.
- Fix serialization and array ordering. Equal artifact bytes, metadata, invocation IDs and declared
  timestamps yield byte-identical output. Pinning timestamps alone is insufficient if IDs vary.
- Preserve atomic output, collision protection and finite artifact bounds. Do not overwrite an input
  artifact or include the output file inside a selected directory; stop writers during hashing.
- Keep stdout machine output separate from stderr warnings. Document success as unsigned generation
  or inspection, never verified provenance. Invalid input exits 2; I/O/tool failures exit 3. M2 digest
  mismatch exit 1 and unsigned-manifest reports remain unchanged.
- Parse bounded untrusted input without network schema fetching, command execution or secret disclosure.
  Document unknown-field/minor-version handling against upstream requirements rather than rejecting
  legitimate future-compatible fields accidentally.

## Acceptance and evidence

- [ ] `record` and `inspect` work offline with explicitly unsigned scope and documented exits.
- [ ] Statement and predicate fixtures validate against pinned schemas; unknown required formats fail.
- [ ] Every emitted field has input evidence and a test that prevents invented build history/identity.
- [ ] Two distinct golden fixtures pass; equal IDs/timestamps/inputs produce byte-identical output.
- [ ] Empty/truncated/multi-record/oversized JSONL, name collisions and unsupported signing cases pass.
- [ ] Output exclusion, changing artifacts, symlink/directory handling and secret redaction retain M2 checks.
- [ ] Existing manifest/verify CLI behavior and independent digest goldens remain unchanged.
- [ ] `make test`, `make race`, `make lint`, the memory gate and image smoke checks pass with evidence.

Use [M1/M2 validation](../testing/m1-m2-validation.md) for the existing memory/image procedure.
These are future M3 gates. Record exact schema revisions/checksums, toolchain, fixtures, commands,
outputs and skips; update the README's non-claims along with the implementation.
