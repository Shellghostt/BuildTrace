# BuildTrace artifact observation operation v1

Build-type identifier:
`https://github.com/Shellghostt/BuildTrace/blob/main/docs/build-types/record/v1.md`.

This type describes an unsigned recording of existing artifacts and metadata. BuildTrace does not run
or witness their original build. SLSA's `buildDefinition` and `runDetails` fields describe this recorder
contract; placing values in those fields does not authenticate the original build.

## Field meanings

| Field | Input and meaning | Independent check |
|---|---|---|
| `subject[].name` | Canonical repository-relative selected path; unique across the recording | Compare with the artifact selection |
| `subject[].digest.sha256` | M2 streaming file or canonical directory/symlink digest | Recompute from artifact bytes under ADR 0004 |
| `buildType` | This versioned constant | Compare the URI; no identity is authenticated |
| `externalParameters.artifacts` | Caller-selected names/paths | Compare with the selection; paths contain no host root |
| `externalParameters.assertedSource` | Optional explicit URI/full commit, labeled `caller_assertion` | Compare the claim with independently obtained source; it does not prove artifact origin |
| `internalParameters.observedCheckout` | Checkout commit, dirty state and optional sanitized network remote observed during recording | Reinspect the checkout; it does not establish the original build source |
| `internalParameters.recorder` | Binary version, compiled Go version, optional current git version, OS and architecture | Inspect the recorder; these are not the artifact's original build tools |
| `internalParameters.observedArtifacts` | Hashed artifact name, kind and byte count | Recompute kind/count under ADR 0004 |
| `resolvedDependencies` | Optional asserted source only, annotated `caller_assertion` | A declared source claim, not discovered dependencies |
| `runDetails.builder.id` | Explicit recorder label; default `https://github.com/Shellghostt/BuildTrace#local-recorder` | No authenticated identity check |
| `runDetails.metadata.invocationId` | Explicit public ID, or canonical statement hash with that field omitted | Recompute the default hash; it identifies the recording, not a witnessed build |
| `startedOn` / `finishedOn` | Explicit paired original-build time claims, normalized to UTC | Compare caller evidence; the recorder does not authenticate these times |
| `byproducts` / `builderDependencies` | Omitted | No such outputs/dependencies were captured |

The statement uses `_type: https://in-toto.io/Statement/v1` and
`predicateType: https://slsa.dev/provenance/v1`. SLSA specification 1.2 retains the `/v1` predicate URI.

## Inputs and canonical form

`record --artifact <path>` is repeatable, with 1–1,000 selections. Paths may be relative to `--repo`
or absolute within its resolved root; emitted paths/names are relative with forward slashes.
Parent symlinks cannot escape the root. Terminal symlinks are observations of target strings, never
followed; absolute targets make their digest host-specific without emitting the target path.
Directories use the globally sorted, bounded byte format in
[ADR 0004](../../adr/0004-m2-canonical-hashing-and-verification.md).

`--source-uri` and `--source-commit` must be supplied together. Local/relative source URIs and abbreviated
commits are rejected. Network URI credentials, query strings and fragments are removed, including from
observed remotes and builder labels. Builder labels may instead be opaque URNs. No arbitrary environment
variables, build command, hostname or absolute host root is copied into the statement. Explicit public
IDs and URI path components are caller-controlled; do not put credentials or private data in them.

`--started-on` and `--finished-on` must be supplied together as RFC 3339 timestamps. Preserve precision
after UTC normalization and require start no later than finish. Neither the clock nor `SOURCE_DATE_EPOCH`
is an implicit original-build time. `--invocation-id` takes a public identifier up to 4,096 bytes.
URI-shaped IDs receive the same credential/query/fragment removal. Without an ID, hash the compact
statement with invocationId omitted and prefix its lowercase SHA-256 with `sha256:`.

Sort subjects, artifact selections and observed artifacts by name. Struct fields have a fixed order;
JSON map keys sort lexicographically. Emit compact UTF-8 JSON without HTML escaping, then LF.
Equal bytes, metadata, IDs and times produce equal output. Runtime/checkout metadata is part of the
input: pinning timestamps alone does not make different recorder hosts/toolchains identical.

`record --sign none` is the default and the only supported signing mode in M3. Stdout contains only
the statement; stderr declares unsigned scope and reports dirty-checkout warnings. `--out` uses
atomic sibling-file replacement and cannot overwrite/include an artifact. Redirected stdout must
also be kept outside selected artifacts. `record` does not generate `buildtrace.json` as a byproduct.

## Inspection and limits

Inspection parses one LF/CRLF-terminated JSON line offline, limited to 16 MiB, 64 nesting levels,
200,000 JSON tokens and 1,000 entries per subject/resource list. Strings used as identifiers/paths
are limited to 4,096 UTF-8 bytes with no control characters. Empty, unterminated, malformed, duplicate-key,
pretty-printed and multiple records are invalid. It neither opens subjects nor runs git or any command.

Unsupported statement and predicate URIs fail explicitly. Unknown compatible fields are ignored for
the summary and preserved in the JSON report's `statement`; field names match case-sensitively.
Unknown build-type URIs are displayed with uninterpreted semantics. Success is an unsigned inspection,
never artifact or signature verification. Invalid input exits 2; I/O/tool failures exit 3.

This operation preserves M2 `manifest` and `verify --manifest` byte formats, reasons and exit codes.
Signing, policy, dependency discovery, SBOM and reproducibility checking remain later milestones.
